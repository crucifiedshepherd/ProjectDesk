# Деловик :0 (ProjectDesk)

Личное десктопное приложение для macOS и Windows: ежедневник с задачами и группами, заметки с собственными категориями и полями, сводка по внесённым данным и учёт сбережений. Всё хранится локально, без аккаунтов и облака.

> Тёмная тема, одно окно, боковое меню, иконка в трее. Запускается одним кликом как обычная программа.

## Возможности

### Ежедневник (главный экран)

- **Статистика:** выполнено сегодня, задач в работе, выполнено всего (с процентом).
- **Задачи и группы:** быстрое добавление через «+», группы дел (например, дисциплина → лабораторные), дела вне групп идут общим списком.
- **Важность** (необязательно): `!`, `!!`, `!!!`, `ПРЯМЩА`. Меняется кликом по метке.
- **Дедлайны:** поле даты у каждого дела.
- **Переименование на месте:** двойной клик по названию дела или группы.
- **Перетаскивание:** перенос дел между группами и из группы.
- **Завершено:** выполненные дела уходят из основного списка в раздел «Завершено» (с датой), их можно вернуть; сразу после отметки доступна кнопка «Отменить».
- **Тепловая карта** выполненных задач за 12 недель и список ближайших дедлайнов.

### Заметки

- Список с поиском и разбивкой по категориям, редактор с автосохранением.
- **Категория** задаётся своим названием (например, «Бизнес-идея», «Кандидатская»).
- **Поля** «название: значение» для структурированных данных; пустые поля подсвечиваются.
- Новая заметка в категории получает названия полей из последней заметки этой категории.

### Сводка

- Заметки карточками: поля сжато, незаполненное показывается красным прочерком «—», счётчик пропусков и фильтр «Только с пропусками». Клик по карточке открывает заметку.
- **Сбережения:** счета с суммами, итог, изменение за 30 дней и график динамики (история ведётся автоматически).
- Кнопка **«Скрыть суммы»** прячет все цифры и размывает график.

### Система

- Иконка в трее: клик открывает окно, правый клик даёт меню «Открыть / Выйти».
- Закрытие окна сворачивает приложение в трей, а не завершает его.

## Запуск для разработки

### Требования

- [Node.js](https://nodejs.org) (LTS)
- [Rust](https://rustup.rs)
- **macOS:** `xcode-select --install`
- **Windows:** [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (рабочая нагрузка «Разработка классических приложений на C++») и WebView2 (в Windows 10/11 обычно уже установлен)

### Команды

```bash
git clone https://github.com/crucifiedshepherd/ProjectDesk.git
cd ProjectDesk
npm install
npm run tauri dev
```

Первая сборка Rust занимает несколько минут, дальше запуск быстрый.

## Сборка приложения

```bash
npm run tauri build
```

Готовые файлы появятся в `src-tauri/target/release/bundle/`:

- **macOS:** `macos/*.app` и `dmg/*.dmg`. Перетащите `.app` в «Программы». Приложение не подписано, поэтому при первом запуске нужно открыть его через правый клик → «Открыть».
- **Windows:** `nsis/*.exe` (установщик) и `msi/*.msi`. SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

### Сборка под Windows через GitHub Actions

Если под рукой нет Windows, установщик собирает GitHub:

1. Вкладка **Actions** → **Build Windows** → **Run workflow**.
2. После завершения скачайте артефакт `delovik-windows` со страницы запуска.

Workflow запускается также при пуше тега вида `v*`.

## Где хранятся данные

База `deskdata.db` лежит в папке данных приложения, не в репозитории:

- **macOS:** `~/Library/Application Support/com.shepherd.projectdesk/`
- **Windows:** `%APPDATA%\com.shepherd.projectdesk\`

Схема версионируется через `PRAGMA user_version` (миграции в `src/db.ts`), поэтому обновления приложения не стирают данные.

## Структура проекта

```
src/
  App.tsx            каркас: боковое меню и панели поверх главного экрана
  App.css            все стили и тема
  db.ts              работа с SQLite: миграции, задачи, заметки, сбережения
  components/        Sidebar, EditableText, TaskInput, TaskRow
  views/             Daily (ежедневник), Notes (заметки), Summary (сводка)
src-tauri/
  src/lib.rs         трей, сворачивание в трей, подключение плагинов
  tauri.conf.json    настройки окна и сборки
  capabilities/      разрешения для плагинов
.github/workflows/   сборка под Windows
```
